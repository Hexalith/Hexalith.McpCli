# Canonical scope upgrade (2.0.0)

The public CLI now normalizes valid tenant identifiers to lowercase and reserves `system` from variable tenant input. Operations that run in a platform namespace declare their `platform:<scope>` value in Contracts metadata. Discovery reports `platformScope` for those operations and omits the per-call tenant argument.

`Hexalith.McpCli.Abstractions` 2.0.0 was published alone for the coordinated dependency upgrade, contrary to AD-17's one-time bootstrap/shared-version rule. On 2026-11-06 the owner separately accepted 2.0.0 as a fixed historical process deviation; the decision does not make that publication compliant or permit another bootstrap. The `Hexalith.McpCli` tool was not published at 2.0.0. The first paired release published both package IDs at the shared semantic-release version 2.0.1. Subsequent paired releases use their newly selected shared version; do not reuse the occupied Abstractions 2.0.0 identity. Review callers that supplied `system` or a tenant for an operation with a declared platform scope. Published legacy modules with an explicit fixed `system` tenant remain readable during the coordinated package transition.

The paired release verifies exact-source CI, immutable staged package bytes, cross-platform smoke, and public NuGet publication. A user-authorized automated acceptance records its bypass of manual client sessions without claiming those sessions occurred.

Independent Abstractions publication is now closed by the public tool's NuGet presence. Historical recovery is verification-only for the three exact tag/SHA bindings in [the bootstrap history](bootstrap-history.md); it requires an already-public package and obtains no publication key or release-write permissions. The separate 1.1.0 historical decision and the unchanged retrospective verdict are recorded there. Platform-scope reconciliation does not authorize publication.
