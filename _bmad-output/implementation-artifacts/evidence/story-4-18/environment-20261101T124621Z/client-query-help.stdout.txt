Description:
  Run a declared query

Usage:
  Hexalith.McpCli query [<operation>] [options]

Arguments:
  <operation>  Canonical read operation

Options:
  --payload <payload>            JSON, @file, or - for stdin
  --aggregate-id <aggregate-id>  Explicit aggregate identifier; canonical uppercase ULID in ULID-kind modules
  --entity-id <entity-id>
  --page-size <page-size>
  --offset <offset>
  --cursor <cursor>
  -?, -h, --help                 Show help and usage information
  --url <url>                    EventStore gateway URL
  --token <token>                Gateway bearer token
  --tenant <tenant>              Session tenant
  --actor <actor>                Trusted operator actor
  --allow-tenant-override        Allow MCP per-call tenant selection
  --profile <profile>            Connection profile
  --format <format>              json or table
  --output <output>              Write the result to a file
  --read-only                    Disable command submission
  --strict                       Reject any Catalog diagnostic
