## Findings

### Aggregate architecture and contract reconciliation

1. **Blocking — a result can replace the private profile store.** A config mutation validates and preflights `--output`, changes the store, then writes its success document to that same path (`src/Hexalith.McpCli/Cli/CliRunner.cs:671-675`; the other mutations use the same order at `:583-586`, `:613-616`, and `:644-647`). The shared writer also serves display and execution results and truncates an existing target (`src/Hexalith.McpCli/Cli/CliOutput.cs:99-123,189-215`). The recorded isolated run used `--output ~/.eventstore/mcpcli.json`; the command exited 0, replaced all profiles with a result document, and a later profile read failed (`_bmad-output/implementation-artifacts/deferred-work.md:393-395`). The edge-case lens reproduced this with the current Release CLI. This crosses Stories 2.2–2.3's private-store promise and Story 2.11's result-file behavior. **Disposition: fix now.** Refuse output paths that resolve to the store or its lock/temp identity for every result-writing verb, including aliases; add a regression that checks exit, both channels, profile bytes, and a subsequent read. Prevention: include owned application files in output-destination preflight tests.

2. **Blocking — an invalid profile name is accepted.** Story 2.2 requires a name outside `^[a-zA-Z0-9_-]{1,64}$` to fail without writing (`_bmad-output/planning-artifacts/epics.md:569-572`), but `ProfileStore.ProfileNamePattern` ends with .NET `$` (`src/Hexalith.McpCli.Core/Settings/ProfileStore.cs:364-365`), which also matches before a final newline. The earlier Release reproduction stored `"dev\n"` as a separate profile (`_bmad-output/implementation-artifacts/deferred-work.md:221-223`). **Disposition: fix now.** Use `\z` and test trailing newline through both the store and CLI. Prevention: pin absolute-end regex cases whenever a public name grammar is introduced.

3. **Accepted, unreconciled deviation — the live query used the authorized running topology.** The parent epic still says to start the existing EventStore AppHost from root-declared checkouts (`_bmad-output/planning-artifacts/epics.md:664-667`), while the approved Story 2.5 spec permits reuse of the already running local topology (`_bmad-output/implementation-artifacts/spec-2-5-run-a-valid-query-through-the-gateway.md:29`). The runbook records the differing runtime revisions, one successful page, and the `index` routing candidate (`_bmad-output/implementation-artifacts/query-spike-2-5.md:14-20,323-345`). This was a user-authorized substitution, not a missing live proof. **Disposition: accept the delivery, propose spec reconciliation.** Update the parent epic/context to state the approved evidence path; leave Tenants maintainer confirmation to Story 4.8. Prevention: when an approved story changes a parent criterion, record that change in the parent contract.

The production project-reference direction remains Abstractions → Core → MCP/CLI; the only Core project-file change in this range grants internal access to the CLI and Core tests (`src/Hexalith.McpCli.Core/Hexalith.McpCli.Core.csproj:7-15`). No new production package or reverse project reference was found. The largest production growth was `CliRunner.cs` 479→843 lines and `CliOutput.cs` 67→415 lines, from the baseline and current files; inspection found related binding and result-output responsibilities, not a separate god-class defect. `ProfileStore.Set` and `ValidateSet` duplicate value construction (`src/Hexalith.McpCli.Core/Settings/ProfileStore.cs:150-167,222-234`), but the branches currently agree, so maintenance risk alone is not routed as a defect.

### Diff review and verification lens

4. **Unverified platform behavior — Windows profile guarantees and native output inspection have no platform run.** Story 2.3 declares Linux and Windows ACL verification (`_bmad-output/planning-artifacts/epics.md:614-617`). The two Core Windows ACL tests skip on Linux (`tests/Hexalith.McpCli.Core.Tests/ProfileStoreTests.cs:580-607`), and the CLI Windows output tests also skipped in this run. The shared CI workflow uses Ubuntu (`references/Hexalith.Builds/.github/workflows/domain-ci.yml:208,666,742`); native macOS and FreeBSD `stat` branches are present (`src/Hexalith.McpCli/Cli/OutputFileType.cs:41-54`) but unexecuted here. These gaps were already recorded (`_bmad-output/implementation-artifacts/deferred-work.md:184-188,380-382,397-399`). **Disposition: defer to the planned platform gate, with explicit acceptance evidence required.** Run the Core and CLI suites with isolated profile homes on Windows, and the output-preflight cases on each intended native ABI. Prevention: tie each platform-specific acceptance criterion to a CI lane before declaring it done.

5. **Known uncertain-outcome gap — a post-acceptance output failure loses command IDs.** The executor can submit one Command successfully, but a later `--output` failure is caught as `internal_error` without the returned message or generated correlation ID (`src/Hexalith.McpCli/Cli/CliRunner.cs:763-795`; `_bmad-output/implementation-artifacts/deferred-work.md:390-392`). The `/dev/full` regression proves one Gateway request and this no-result path (`tests/Hexalith.McpCli.Cli.Tests/ExecutionFailureCommandTests.cs:160-170`); the README warns against blind retry (`README.md:101,118`). **Disposition: defer a result/error contract decision, already tracked.** The product and architecture owners should decide how to preserve a safe lookup identifier after an accepted Command when its result cannot be written. Prevention: test post-submission output failures in the same story that defines a traceable result.

6. **Conditional output corruption under `/dev/`.** The writer treats any resolved `/dev/*` path except `/dev/shm/*` as a device (`src/Hexalith.McpCli/Cli/CliOutput.cs:239-241`) and directly writes without truncation when that predicate is true (`:143-151`). If a seekable regular file is mounted or created there and a shorter result is written, old trailing bytes remain. This path was established from code; no accessible fixture reproduced it in this review. **Disposition: defer pending a mounted regular-file fixture, then select direct writing by inspected file type rather than path prefix.** Prevention: classify special output targets by file identity in both preflight and writer.

The adversarial and edge-case lenses independently found finding 1; the adversarial lens also identified finding 6. The verification-gap lens found finding 4 and the already tracked privileged Unix mode-bit test gap (`_bmad-output/implementation-artifacts/deferred-work.md:401-403`). That privileged case remains a test follow-up, not a reproduced runtime defect. The code lenses inspected the changed Settings, Execution, CLI, and related tests; they did not line-review unrelated tooling and submodule changes in the 190-path diff.
