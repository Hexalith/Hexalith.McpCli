HighVAL-20260923B-01 · AD-7, AD-9

Raw validation rejects fields the executor promises to replace

AD-9 validates raw Payload against the final Schema before envelope filling. Removing envelope-owned fields from required still leaves their type and pattern checks in place. A raw null idempotency field can fail before a supplied key overwrites it; an invalid correlation field can fail before its overwrite.

Resolution

Define a pre-fill validation pass for ordinary Payload fields and explicit ownership checks for envelope fields. Fill, then validate the full object against the advertised Schema. Test null idempotency and overwritten correlation inputs.

HighVAL-20260923B-02 · AD-3, AD-7, AD-9, AD-19

Decoration property references can alias different roles

tenantProperty and actorProperty may resolve to one JSON property. Different compliant fill orders can then send different Payload values. A correlation or actor field overlapping the aggregate source can change routing. Attribute strings also lack a rule for CLR names versus serialized names such as [JsonPropertyName("party_id")].

Resolution

Resolve each declared CLR member to its effective serialized property once, then reject unresolved or colliding roles at Catalog build. Cover aggregate overlaps and renamed properties in fixtures and the PRD diagnostic contract.

Spine AD-7/9/19 · PRD decoration table · Adversarial evidence

HighVAL-20260923B-03 · AD-6/7, Tenants

Current Tenants audit queries ignore valid filters

The tool's chosen case-sensitive Payload wire uses From, To, and Category. Today's Tenants handler reads lowercase from, to, and category, so valid filters can be silently ignored.

Resolution

Record an upstream Gateway-ready prerequisite to align the handler and declared wire contract. Prove it with a live vector using non-default filters and asserting the filtered result.

Spine AD-6/16 · Source and API evidence

HighVAL-20260923B-04 · AD-20, Tenants

Current Tenants handlers ignore envelope-only paging

AD-20 places paging only in SubmitQueryRequest.Paging. Checked Tenants handlers read paging from Payload and do not read QueryEnvelope.Paging. A non-default page request can therefore receive the default page.

Resolution

Make the Tenants paging migration an explicit v1 gate, or revise AD-20 and the PRD. A live vector should assert a non-default page size and a subsequent cursor.

Spine AD-20 and Deferred · Handler and Gateway evidence

MediumVAL-20260923B-05 · AD-12/13

Define what output options do under mcp

Every verb accepts --format and --output, but the stdio protocol owns stdout. The spine does not define whether mcp --format table or mcp --output file is rejected, ignored, or handled elsewhere.

Resolution

Choose one startup behavior, preserve stdout as JSON-RPC, align the option table, and test both forms.
