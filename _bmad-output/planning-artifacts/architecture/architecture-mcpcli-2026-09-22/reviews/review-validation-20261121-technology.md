## Findings

1. **Medium · The CLI result writer can overwrite the profile store.** AD-14 assigns exclusive writes to `ProfileStore`. The state convention repeats that guarantee. In `config use`, the CLI checks the output destination, changes the profile, then writes the result. Output preflight checks the destination type and access. For an existing regular file the writer truncates the destination and copies the result into it. The existing Story 2.11 ledger records a successful invocation that left only the active-profile result, making every stored profile and token unavailable. This requires an explicitly conflicting output destination. **Disposition — qualify AD-14 now and refer to the existing deferral.** To close it, reserve the active store and its transaction files during output preflight, account for aliases, and verify the previous profile bytes survive a refused invocation. 2. **Medium · AD-7 drops valid getter-only input members.** The rule removes every getter-only member lacking a constructor parameter. With `JsonObjectCreationHandling.Populate` at the property or type level, System.Text.Json can deserialize into an existing collection. Core’s metadata resolver explicitly retains these members. A regression test verifies that the published schema accepts `Tags` and `Lines` and deserialization fills both collections. Implementing AD-7 literally would remove valid input from closed schemas and cause both Heads to reject it. **Disposition — correct the rule.** Retain getter-only members that support in-place population under the effective serializer metadata. Continue omitting computed members with no input path. 3. **Medium · AD-9 gives the wrong error path for a malformed aggregate ID read from the payload.** The rule says aggregate syntax violations use `/aggregateId`. If an explicit argument is absent and a mapped accessor supplies the invalid value, the executor returns the escaped JSON Pointer for the serialized property. The fixture’s `key/~` member yields `/key~1~0` with zero Gateway calls. An explicit argument that conflicts with the accessor does yield `/aggregateId`. Callers use the pointer to identify which input to correct. **Disposition — reconcile AD-9 and FR-15 with the tested contract.** Specify the mapped-pointer case and retain the envelope pointer for explicit arguments, conflicts and the fallback branch.
