# Architecture consistency review · 21 November 2026

Reviewed the feature spine against McpCli `e79b7f8b`, Platform `25887836`, the published Folders 2.0.1 source and the adopted AD-23 decision.

| Decision | Where independent implementations could disagree | Required interpretation |

| AD-9, command outcomes | Two callers could confirm the same trusted adapter, then retry an uncertain command with different keys. A dispatched invocation submits once. Deliberate replay requires the original caller-supplied key, the same logical command and tenant, and a trusted adapter confirmed for that command type on the target deployment.
